# Synthetic example datasets

All datasets and records in this directory are synthetically generated for
demonstration and testing. They do not describe real people, vehicles,
locations, organizations, claims, or incidents.

The values are designed to resemble realistic connected records so the examples
can demonstrate graph construction, selection, search, analysis, expansion,
editing, and progressive loading. They must not be treated as operational or
authoritative data.

`intelligence_case.json` is the shared vehicle, location, time, and observation
dataset used by the executable data-loading examples and documentation snippets.
