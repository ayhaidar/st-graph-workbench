# Security policy

## Supported versions

Security fixes are applied to the current `0.1.x` release line while it is
supported. The policy will be updated when another release line is introduced.

## Report a vulnerability

Use GitHub's **Report a vulnerability** option in the repository Security tab
to submit a private advisory. Do not place exploit details, credentials,
private records, or sensitive deployment information in a public issue.

Include the affected version, impact, reproduction steps using synthetic data,
and any mitigation you have identified. If private vulnerability reporting is
temporarily unavailable, open a public issue requesting a private contact
channel without disclosing the vulnerability itself.

## Scope

Reports about the Python package, bundled browser component, packaged assets,
and release artifacts are in scope. Vulnerabilities in Streamlit, Cytoscape.js,
or another dependency should also be reported to that upstream project when
appropriate.
